КИТОБХОНАИ ЭЛЕКТРОНӢ: ОҒОЗИ СЕРВЕР ВА ҲИСОБҲО

Талабот: Python 3.10 ё навтар. Китобхонаҳои иловагӣ лозим нестанд.

1. Дар PowerShell ба ҷузвдони лоиҳа гузаред:
   cd "C:\Users\SZM\Desktop\китобхонаи донишгоҳ"

2. Агар ҳисоби админ ҳанӯз сохта нашуда бошад, онро созед:
   python server.py create-admin admin
   Паролро дар худи терминал ворид намоед.

   Агар ҳисоби `admin` аллакай ҳаст, вале паролашро намедонед, онро аз терминал нав кунед:
   python server.py reset-admin admin
   Пароли навро ду бор ворид намоед. Парол бояд камаш 10 аломат дошта бошад.

3. Серверро оғоз кунед:
   python server.py

4. Дар браузер кушоед:
   http://127.0.0.1:8000

Файли `index.html`-ро мустақиман бо `file:///...` накушоед: воридшавӣ ва сабти ном API-и серверро истифода мебаранд.

Донишҷӯён метавонанд аз саҳифаи «Вуруд / сабти ном» мустақилона ҳисоб созанд; пас аз сабт онҳо худкор ворид мешаванд.
Сабти номи озод танҳо нақши донишҷӯ медиҳад. Ҳисобҳои омӯзгор ва админро танҳо аз ҷониби админ сохтан мумкин аст.
Паролҳо ҳамчун хэши PBKDF2 нигоҳ дошта мешаванд; матни аслии парол дар база сабт намешавад.

Логин бояд аз 3 то 32 ҳарфу рақам, нуқта, тире ё зерхат бошад. Парол ҳадди ақал 10 аломат дошта бошад.
Сервери маҳаллӣ барои санҷиш аст. Барои дастрасӣ аз интернет HTTPS, домен ва танзими амниятӣ лозиманд.
